# Labelled retrieval queries for `codegraph query="search"`, run against koda's
# own source by `index::tests::retrieval_quality_holds`.
#
# Format:  <query> TAB <path>[,<path>...]
# A hit counts as correct when its path ends with any of the listed paths. The
# labels are the file a competent answer has to reach, not the only file that
# mentions the words -- that distinction is the whole point of the measurement.
#
# Reported: Recall@10 (did a correct file appear at all) and MRR@10 (how high).
# Adding a query is cheap and welcome; changing a label to make a run pass is
# how this harness stops being evidence.
